ÉCLORA — DOSSIER PRÊT À HÉBERGER

Site statique : aucune installation ni compilation nécessaire.

1. Décompressez ce ZIP.
2. Téléversez index.html, en.html, style.css, script.js et le dossier assets
   dans le dossier public de votre hébergement, en conservant leur structure.
3. La page d'accueil est index.html. La version anglaise est en.html.
4. Connectez votre nom de domaine dans le panneau de votre hébergeur.

Les boutons de réservation ouvrent https://calendly.com/eclorainc/30min.
Le formulaire de contact reste désactivé : il n'envoie ni ne conserve de données.
Les aperçus du portfolio dépendent des sites externes; les liens permettent de les visiter.

Le fichier LISEZ-MOI.txt n'a pas besoin d'être téléversé.
